# STARK Finance Control

Application web locale, prête pour GitHub Pages.

## Fonctionnalités

- Tableau de bord financier
- Revenus et dépenses entièrement modifiables
- Prélèvements récurrents
- Échéanciers avec fréquence et jour
- Pause / réactivation des prélèvements
- Suivi des dettes
- Capital restant et mensualités
- Progression du remboursement
- Objectif d'épargne
- Calcul automatique du montant réellement disponible
- Impression et export PDF via la fonction d'impression du navigateur
- Sauvegarde automatique dans le stockage local du navigateur
- Design futuriste sombre, responsive téléphone / ordinateur

## Installation sur GitHub

1. Crée un nouveau dépôt GitHub.
2. Envoie `index.html`, `style.css` et `README.md`.
3. Dans **Settings → Pages**, active GitHub Pages avec la branche principale et le dossier `/root`.
4. Ouvre l'adresse GitHub Pages fournie par GitHub.

## Export PDF / impression

Clique sur **Imprimer / PDF**. Dans la fenêtre d'impression :
- sur ordinateur : sélectionne « Enregistrer au format PDF » si tu veux un PDF ;
- sur iPhone/iPad : utilise le menu de partage/impression du système.

## Données

Les données sont enregistrées localement dans le navigateur. Elles ne sont pas envoyées sur un serveur.

Conseil : utilise régulièrement l'impression PDF comme sauvegarde papier/PDF de ton suivi.

### Épargne manuelle
Tu peux ajouter chaque versement d'épargne avec une date et un montant, puis modifier ou supprimer chaque entrée. Le total épargné et la progression vers l'objectif sont recalculés automatiquement.
